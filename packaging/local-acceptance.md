# DSH 桌面与模型验收

这份表检查真实客户端和模型对话。程序测试不代替这些检查。

记录：系统 ______；DSH ______；AIFS ______；REST ______；模型及模式 ______。保留原始提问、选择、工具参数、结果与最终文件，不记录 API Key。

## 安装与启停

按 [安装说明](README.md) 添加 `.tgz`，启用后状态页应显示“可用”，服务版本与包版本一致。故障时记录页面错误、日志末尾和一次重试结果。

| 操作 | 预期 | 实际结果 |
| --- | --- | --- |
| 启用插件，立即调用工具 | 十个工具可见；等待所属后端启动 | |
| 启动失败 | 工具保留、错误明确；不假称保存或出卡成功 | |
| 可用时重试 | 不重复启动，不改变端口 | |
| 停用或重载 | 旧后端退出；重载后只启动一个后端 | |
| 重开 DSH | 计划和卡片保留，重新获取下载地址 | |
| 缺运行包后补回并重试 | 同一组工具恢复可用，不连接其他服务 | |

## 基础出卡

检查导出文件在工作区的 `aifs-inputs/` 内：独立计算各用一个目录，同一计划的后续卡沿用计划目录、各任务一个子目录。旧卡保留；目标文件已存在且内容不同时，应提示冲突、不覆盖。工具返回路径不等于已经写入文件。

测试 A／B／C 共用已确认输入：H₂，`H 0 0 0 / H 0 0 0.74`，Angstrom，电荷 0、多重度 1，PBE/def2-TZVP。这是接口测试设置，不是方法优选。

| 编号 | 需求或动作 | 预期 | 实际结果 |
| --- | --- | --- | --- |
| A | 只算单点，给输入文件 | `generate_rest_input` 一次生成并校验，不建计划 | |
| B | 优化后算单点，给当前文件 | 自动保存两步，先给优化卡；后续等待优化坐标和结果单位 | |
| C | 优化后算力或数值偶极 | 同 B，不能拿初始结构替代 | |
| D | 明确要求保存单点 | 创建计划、生成已存卡；重开后找回 | |
| E | 给 Bohr 坐标，第二个 H 的 z=1.4 | 正文 `unit="bohr"`，数字不变 | |
| F | 分别缺单位、电荷、自旋或基组 | 只问缺项，不猜默认后出卡 | |
| G | 找回没有 unit 的旧卡 | 正文不改，标明单位未记录；确认后修订生成新卡 | |

出卡应有有效正文和文件名。保存卡可下载；有 DSH 文件工具时导出后端原文，没有时显示校验过的正文。失效链接通过 `get_aifs_card` 更新，不为修链接重做科学方案。回复只讲当前文件、等待步骤和下一步；内部编号按排错需要展示。

## 修订与结构来源

| 动作 | 预期 | 实际结果 |
| --- | --- | --- |
| 补回优化坐标及单位 | 用 patch 更新相关任务；保留电荷、自旋和方法 | |
| 只给新坐标，没给单位 | 等待结果单位，不继承起始或旧结果单位 | |
| 两个优化任务并存 | 每个下游引用正确的直接优化依赖 | |
| 改上游结构、电子态、方法、基组或设置 | 引用它的下游坐标和单位清空，旧卡标为不适用但仍可下载 | |
| 同时改上游并提交下游坐标 | 先失效；新结果后续单独补回 | |
| 替换一份优化结果，仅更新一个消费者 | 未同步更新的其他消费者恢复等待 | |
| 只改说明或文献 | 结构不失效，正文相同的卡复用 | |
| 只改某一步基组、增加或删除任务 | 只提交 patch，其他参数和历史记录不丢失 | |
| 版本冲突或非法修订 | 原记录不变；读最新版本后再改 | |
| JSON 失败或调用中断 | 先读保存状态，不假称失败调用成功、不重写整份计划 | |

旧卡是否可用看 `is_applicable_to_current_plan`；原生成版本看 `is_current_plan_version`。

## 新手提问与方法选择

保留原始新手提问见 [产品验收案例](../docs/reviews/2026-10-08-product-acceptance-scope.md)。分别用官方和自定义模型测试。

- 给出有条件、有理由的方法建议；无可靠文献时说明不足，不编造引用、误差或实验值。
- 泛函和基组分别选择，优化和最终能量分别选择。已明确的组合不重复问。
- 面板允许适用的多个候选和自定义答案；不固定三项、不为凑数列不适用方法。TPSS 与 TPSSh 区分；双杂化优化说明数值力成本。
- 预选、取消、未提交或“不知道”不算确认。没有问答工具时在聊天中问，不声称已弹窗。
- 先查询能力，保留用户选定的准确方法名/parser；不静默换成 PBE0，不把 wB97X-D 改成 wB97X-D3。
- 普通规划指导上限为两次搜索、三次抓取；连续两次抓取失败后停止补查。记录实际次数，这不是程序硬限制。已确认参数不重复检索；明确深入核对时可继续。

## 光电子谱、ADE 与零点能

先问：“我有一个分子团簇的阴离子光电子谱，想用计算和实验对比。我不知道该算什么，请帮我安排任务和选择方法，准备输入文件。”再提供实际结构和实验信息。

模型应区分电子 VDE、电子 ADE、含零点能修正的 ADE₀ 和完整谱形。只算电子 VDE 不机械加平衡 ZPE 差；0–0 ADE 需要参与物种各自的频率/ZPE；有限温度量另确认温度和标准态。换分子不复制 Al₃ 自旋或方法，单原子不安排分子振动频率。

固定回归设置：Al₃⁻/Al₃，电荷 −1/0、多重度 1/2；优化与频率 PBE0/def2-TZVP，最终单点 wB97M-V/aug-cc-pVTZ，同时比较 ADE 与 VDE。

| 检查 | 预期 | 实际结果 |
| --- | --- | --- |
| 任务 | 两种优化、三个单点、两种频率/ZPE、分析项；频率等各依赖正确优化 | |
| 几何 | 中性自身几何与中性在阴离子几何上分开；缺优化坐标或单位时等待 | |
| 方法 | 频率保留 PBE0；中性双重态走 analdrv，不用未经核对的 VV10 Hessian | |
| VDE | `E(neutral,R_anion)-E(anion,R_anion)` | |
| 电子 ADE | `E(neutral,R_neutral)-E(anion,R_anion)` | |
| ADE₀ | 电子 ADE 加 `ZPE(neutral)-ZPE(anion)`；直接依赖两能量和两 ZPE 来源 | |
| 结果不足 | 没运行、缺一项 ZPE、单位不明或明显虚频时，不报告最终实验 ADE | |
| 实验解释 | 不将 VDE 无条件等同峰顶，或 ADE₀ 等同首个可见起点；完整谱形说明额外能力 | |

能量与 ZPE 需注明物种、状态、方法、单位和最小值检查。不能混用频率方法的 `E+ZPE` 总量和另一方法的电子能，也不能用 298 K Gibbs／焓代替 ZPE。`analysis_only` 不表示算完。后端不自动读取输出或计算公式。

按 [REST 能力清单](rest-coverage.md) 检查保存参数、等待条件、正文和原文导出：

| 需求 | 检查点 | 实际结果 |
