# DSH 桌面插件走查

适用于 macOS arm64 和 Windows x64 调试包。用户验证真实 DSH 桌面与模型对话，程序和打包检查由构建流程完成。记录操作系统、DSH 版本和插件版本，分别保留各平台的实际结果。

## 第一次安装

1. 打开对应系统的 DSH 桌面版，记下系统及 DSH 版本：________。
2. 「插件 → 添加插件」填入下载的 `.tgz` 文件在自己电脑上的完整路径，安装并启用。源码构建的安装包位于仓库 `dist/` 目录。升级时卸载旧版后安装，完全退出并重开 DSH；无需手工解压。
3. 打开 AIFS 状态页面，记录状态、版本、数据目录、日志路径：________。
4. 不需要先启动 `start-local.sh`，它属于原来的 Web 开发方式。
5. 在 DSH 模型设置选已有官方或自定义模型。自定义模型需支持工具调用；网页工具能否使用要另查。记录提供方、接口协议与模型 ID，**不要记录密钥**：________。

如果找不到 AIFS 页面，记录插件安装/加载错误和 DSH 版本；如果页面显示启动失败，复制页面错误及日志最后一段。点击重试一次并记录结果。

## 最短对话（诊断连通性）

先输入：

> 请用 AIFS 给 H2 保存一个单点电子能计划。结构为 H 0 0 0 和 H 0 0 0.74，单位 Angstrom，电荷 0，自旋参数 1。我明确指定 PBE/def2-TZVP，当前无需文献推荐。请显示保存后的计划 ID、任务 ID 与状态，并生成对应 .in 输入卡。

记录真实工具调用、计划 ID、卡片 ID、版本、下载文件内容及 SHA-256。应该先调用 `create_aifs_plan`，满足参数门槛后调用 `generate_aifs_task_card`。若模型只有口头计划而没有工具结果，计划没有保存。

关闭并重开 DSH，在新会话输入：

> 用 AIFS 找回计划 ID ________，读取卡片 ID ________，给我当前有效的下载链接。

确认正文与上次下载一致。动态端口会变，旧聊天中的旧链接可能失效；`get_aifs_card` 返回本次地址才是有效链接。

## 启停

后端启动失败或所需服务尚未注入时，模型仍应保留 AIFS 工作流指导，说明保存/出卡尚未完成并给出恢复步骤。不得自行写 .md 与 .in 后称已存入 AIFS 或已校验；正常提问不应默认导出方案 Markdown。若明确要求草案，标明未校验且未保存。科学参数已确认后直接说明下一步，不强制“接受/换方案”二选一。

插件启用后，十个工具应立即进入模型请求，无需等后端就绪。启动期间调用会等待；失败后工具仍在，调用返回具体原因。重试恢复后使用当前端口。升级后状态页的服务版本应与安装包版本一致；仅安装文件变新或关闭窗口不能证明旧运行实例已退出。

## 专业流程（完整模型验收）

先用自然需求提问：“请安排 H2 的几何优化，再算优化结构的单点能。用我指定的 PBE/def2-TZVP；坐标 H 0 0 0 / H 0 0 0.74 Angstrom，电荷 0、多重度 1。准备当前能用的输入文件。”普通回复应呈现计算步骤、当前进度、实际下载链接及下一步所需坐标和单位，不默认列出内部 ID、英文状态、工具名、摘要或完整 TOML。若主动要求排错，再提供技术详情。验证生成输入卡未被说成已经完成计算；未经检查不能声称基组目录为空。

参考仓库外 `docs/从零理解-AIFS-与-多步计算工作流.md` 的五组案例。分别用官方模型和支持工具调用的自定义模型检查反应电子能、结合电子能、优化后单点能、力、偶极。

额外检查：缺电荷/自旋不出卡；优化后坐标尚无来源时单点能等待；用户指定方法标记 user；网页使用 `web_search` 再 `web_fetch`，引用带 URL、标题、依据、未整理说明和不确定性；无搜索结果仍可保存计划；冲突证据保留 opposing；REST 不支持步骤明确拒绝出卡。修订后旧卡标明历史版本。

记录：提问、工具名、plan_id/版本、task_id、证据类别、card_id、下载摘要、问题位置。无需把密钥或个人凭据发给开发者。

Windows、Intel Mac、平台签名和正式发布仍未验收。

## 实验 ADE 与零点能

### 回复与计划一致

同一会话保存计划后，对照 `get_aifs_plan` 返回的分析公式与最终回复。ADE 必须使用中性自身优化构型，VDE 必须使用阴离子优化构型；不能把已经正确保存的 ADE 在回复中改成 VDE 加 ZPE 差。频率/ZPE 来源、方法及依赖也应一致。换另一个分子或团簇重复核对，不把某个案例写成默认参数。

检查回复没有将 VDE 与谱峰极大、0–0 ADE 与首个可见谱带起点无条件等同。已生成文件不等于计算已完成；待优化结果的任务直接说明下一步需要的结果，不再附加“预览还是等待”的选择。记录原始模型回复和工具记录，提示词文本检查不算模型验收。

先按普通用户的需求测试：“我有一个分子团簇的阴离子光电子谱，想用计算和实验对比。我不知道该算什么，请帮我安排任务和选择方法，准备输入文件。”再提供实际物种、结构和已有实验信息。应由模型判断目标量并追问会改变方案的缺项，不要求用户先懂 ZPE 或指定全部计算方法。

条件分支：明确对比 0–0 ADE 时，补上所需物种的频率／ZPE；只对比电子 VDE 时，不机械增加平衡结构 ZPE 差；要有限温度自由能时确认温度和标准态；要完整谱图时说明还需要谱学计算。换一个实际分子仍应根据其状态和需求规划，不能复用 Al3 的电荷、自旋和方法。单原子不安排分子振动频率。

下面仅是开发回归案例的已确认参数，用于检查出卡边界，不是 Skill 的默认推荐：Al3−/Al3，电荷 −1/0、多重度 1/2；优化与频率 PBE0/def2-TZVP，最终单点 wB97M-V/aug-cc-pVTZ；同时对比 ADE 和 VDE。另提供已确认单位的起始结构。

- 计划应包含两种优化、三个最终单点、两种频率/ZPE 与能量组合；每个频率任务依赖对应的优化，缺结果坐标或结果单位时不出正式频率卡。
- 频率方法保留 PBE0，不能因为单点用 wB97M-V 就生成其未经核对的 VV10 解析 Hessian。中性双重态选择 analdrv 路径；频率卡覆盖全分子并显式请求 ZPE 报告，缩放约定记入计划。
- `ADE_0 = E(neutral_sp)-E(anion_sp)+ZPE(neutral_freq)-ZPE(anion_freq)`，分析任务直接依赖四项来源。ZPE 修正可正可负，不能只减阴离子 ZPE，也不能把频率方法的 `E+ZPE` 总能量与另一方法的电子能混用。
- VDE 保持 `E(neutral_at_anion_sp)-E(anion_sp)`，不自动加上述平衡结构 ZPE 差。只要求电子能时可省频率，但明确标为“未含 ZPE 的电子能差”。
- 若已有旧计划，修订时保留原任务 ID 和旧版本，补上频率依赖及修正公式，不能声称旧计划已自动升级。
- 没有运行结果时显示“等待能量和 ZPE”，不因 `analysis_only` 就说已算完；只补一个 ZPE、未给单位或发现明显虚频时，不报最终实验 ADE。要求外部结果的物种、方法、单位及最小值检查；不伪造频率或默认拿 298 K Gibbs/焓替代 ZPE。

这是规划和输入卡准备验收。AIFS 尚不执行 REST、自动读取频率结果或计算自由文本能量公式。实际工具记录与回复：________。

## 分别选择优化与最终能量方法

连通测试：“H2 坐标 H 0 0 0 / H 0 0 0.74，单位 Angstrom，电荷 0、多重度 1。用 PBE/def2-TZVP 优化，再用 XYG7/def2-TZVPP 算优化结构的单点电子能。保存计划，给我现在可用的输入卡文件。”这是接口测试组合，不是泛函优选结论。优化卡应使用 PBE；XYG7 卡等待真实结果坐标和单位，补入结果并修订后才生成。检查历史优化卡仍保留原方法。

自然提问：“我想计算 Al3− 的 ADE 和 VDE，请分别讨论优化和最终能量的方法，优先考虑 REST 支持且适用的双杂化。文献不足时先给初步建议。”应先查询能力；方法选择卡说明 REST 支持与适用性，不把 wB97X-D、CCSD(T) 当本版可出卡选项。两种优化可采用同一几何协议，后续阴离子自身几何、中性自身几何、中性在阴离子几何上的能量应采用同一最终能量协议；不能混用另一方法的优化能量相减。读取失败的来源不作为比较证据，不编造误差区间。真实模型表现：________。

## 检索耗时与降级

正常规划应先说明科学路线，再为相关步骤共用一次证据检索。指导上限为两次 web_search、三次 web_fetch（包含重试）；连续两次抓取失败/超时后停止补查，说明证据缺口、保存暂定方案并请求方法确认。记录实际次数及耗时，不把模型指导当硬超时保证。未读到来源不能声称已核验实验值或误差区间。随后只确认参数、出卡或导出文件时，不应为相同方法重新检索。明确要求深入文献核对时可继续检索。检索失败不绕过科学参数和出卡校验。

## 基模建议与证据补强

提问：“H2 坐标 H 0 0 0 / H 0 0 0.74，单位 Angstrom。我不知道电荷、自旋和泛函，请帮我提出单点电子能方案。”

检查模型是否给出带条件、理由和不确定性的候选建议，而非只列缺项。未确认的电荷、自旋仍应为 null，建议留在 notes/assumptions；基模方法建议没有文献时为 provisional，不冒充 web/local 证据。检索不可用时仍能保存待确认计划。用户确认后修订，才允许受支持任务出卡。

需要确认的电子态、泛函和基组，应使用当前会话的 `ask_user_question`，在 DSH 选择卡片中填写。泛函和基组是独立问题：先确认泛函，再根据该方法提供多个适用基组及成本／收敛取舍；不将两者锁成固定搭配。优化与最终能量分别询问，可批量提交相互独立的问题。记录工具调用和实际选择；只选“不了解／请帮我判断”、取消、尚未提交或超时时，不能视为确认后出卡。选择确定的参数后应修订计划并继续，不重复问同样的确认。若当前模式缺少问答工具，应简短在聊天中询问并说明限制，不声称已弹出窗口。具体呈现由 DSH 客户端负责，本机真实界面仍须走查。

分开选择的验收提问：“我想优化水分子，再算单点电子能。请先让我分别选择优化和单点的泛函，再分别选择基组，每个基组问题给出适合当前方法的多个候选。”检查两阶段问题与最终卡片是否一致。另测试“我指定优化 PBE0，基组还没选”和“我指定 PBE0/def2-TZVP”：前者只补基组，后者不重新询问已确认的组合。仅选择泛函、未提交基组时，不得按默认基组出正式卡。阴离子与双杂化任务的基组候选应说明适用条件；有具体限制时允许解释单一候选原因，不能为凑选项提出不适用组合。

另提问频率与 298.15 K、1 atm 热化学需求：模型查询能力并保存适用的 Hessian/thermo 设置，真实优化结果未提供时等待坐标和单位。卡片必须有相应区块，不能声称已计算自由能。对尚未接入的 GW/BSE 或 MD，保存待接入步骤并说明缺口。官方和自定义模型的实际表现：________。

## 坐标单位验收（2026-10-03 新增）

1. 上述 H2 案例下载的 `[geom]` 应出现 `unit = "angstrom"`，坐标仍为 0.74。
2. 另建一个明确使用 Bohr 的 H2 计划（例如第二个 H 的 z=1.4 Bohr），卡中应为 `unit = "bohr"` 且数字仍为 1.4。
3. 只给坐标，不给单位：可以保存计划，状态应为 needs_input，追问单位后修订才出卡。
4. 优化后单点能：前一步尚未运行时等待结果；只补结果坐标但没补单位仍不出卡，确认结果单位后出卡。
5. 找回没有 unit 字段的旧卡：正文和摘要保留，返回 position_unit_status=not_recorded；确认单位并修订计划后生成新版本的卡。
6. 模型应直接使用创建/修订工具中的完整字段定义，不再为了猜 goal、position_source 或 rationale 去用户工作区寻找后端源码。

## 输入卡交付

有 DSH 文件写入/展示工具时，应将 AIFS 返回的原始卡片正文导出为 `.in` 附件，内容和保存摘要一致，不自行重写参数。要求“直接给我输入卡”时可在聊天中展示保存的正文。关闭重开后尝试旧链接，再要求找回：应读取已存卡获得当前链接或附件，不重复生成卡，不修改计划和方法。链接不可用时提供正文/附件；不得只有一个重复失效的 URL。

## 方法比较与接入边界

要求“优化阶段也给出 TPSS、杂化和双杂化候选，不限三个选项”。检查候选是否成为实际可选项，TPSS 与 TPSSh 是否正确区分，理由是否针对几何而非只谈最终能量。适用的 XYG3/XYG7/XYGJOS 优化选项须说明数值力成本；选定后保存 `rest_options.ctrl.numerical_force=true`，出卡正文应一致。不能因为面板扩大就编造精度排名，也不能为凑数列入当前任务不支持的方法。最终电子能仍独立选择，基组另行确认。实际选项数量和呈现由模型与 DSH 客户端共同决定。

对比水分子能量、团簇脱附能、结合能等不同问题：不应一律推荐 PBE0，也不应一律将它替换为 ωB97。检查具体体系/性质证据、长程校正及适用时的双杂化候选、基组/收敛考虑、推荐与排除理由。指定 wB97X、wB97X-V、wB97M-V 与已接入 D3 变体时，应查询准确解析路径，保存原方法名及 xc_parser，不偷偷生成 PBE0 替代卡。wB97X-D 在核对的官方解析器中明确拒绝，不能改成 wB97X-D3。含 VV10 的优化/力需显式数值力，未核对的解析 Hessian/响应组合阻止出卡。程序检查不证明实际 REST 数值表现。

这些是实际对话检查项，程序测试通过不能代替逐项填写实际结果。

## 高级输入与范围查询

请模型用 `get_rest_capabilities` 查询概览与所需区块，依据 [REST 能力范围](rest-coverage.md) 逐项检查频率/热化学、TDDFT/TDA、TS/IRC、固定原子和 SCF 设置。参数须经过计划保存、卡片独立校验、修订后历史版本读取与原文导出。原生 thermo 压力为 atm，geometric thermo 压力为 bar；不要把不同路径的参数混用。记录所用 REST 版本，新增输入尚未完成真实计算验收。

新增案例：

- 已确认的开放壳层离子、wB97X 方法、优化结果坐标和单位，要求频率及 298.15 K／1 atm 热化学：应选择 analdrv Hessian，不应悄悄换成 PBE0 或闭壳层原生路径；坐标未提供时等待。
- 要求偶极与四极矩：任务保存 multipole 1、2 阶及参考原点；原点单位为 Bohr，即使几何用 Angstrom。
- 同时要求 0.1 Hartree 频域响应、FEAST 激发能和第一激发态力：应区分三个任务，确认参考态和根号；响应不冒充激发根，FEAST 不搭配 AO／开放壳层，梯度不依赖 FEAST 根作为同一运行中的梯度来源。
- 要求一维／二维 RRS-PBC：保存核心晶胞索引、向量、平移次数与 k 点参数，说明这是有限团簇后处理。请求三维时保留待核对任务，不用一维卡替代。
