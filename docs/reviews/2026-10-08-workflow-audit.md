## 可复现证据

- `PlanPatch` 合并 `inputs`／`decision` 的变化字段，其他容器整项替换；修订事务核对版本并保存完整快照。
- `/prepare` 要求单位、电荷、自旋和基组，生成后独立校验。旧 `/v1/rest-inputs` 省略参数仍能返回默认值；普通 legacy 渲染可接受坏坐标，独立校验会拒绝。两入口保证范围不同。
- 测试计划中把两个最终能量分别设为 PBE 与 B3LYP，分析填任意非空文本，计划创建成功：后端尚不通用检查能量可比性和公式。
- 调用方填写 `source=evidence` 和网页引用，输入齐全时可以出卡：引用存在或来源标签不能证明文献内容已核实。

这些是当时的受控探测，不是发生频率、方法精度或安全利用结论。代码入口：`workflow_models.py`、`workflow_store.py`、`models.py`、`api.py`、`rest/renderer.py` 和插件 `client.ts`。

## 后续建议

| 改进 | 验收要求 |
| --- | --- |
| 可信用户确认 | 确认事件由宿主记录，模型不能自报凭据；取消或参数变更不能沿用确认 |
| 独立结果记录 | 记录真实结果来源、内容摘要和对应任务；外部结果可导入，不虚构运行完成 |
| 科学组合约束 | 分别检查最终能量协议、单位、系数和修正来源；允许优化、频率与单点使用不同方法 |
| 本机调用隔离 | 先明确威胁模型，再验证读写、下载、重启和浏览器访问边界 |
| 产品验收 | 留存真实客户端、模型、文件交付和结果回填的原始记录 |

保留现有模型校验、独立输入校验、任务图、事务、历史卡和升级备份。下一轮改动按实际需求验证，不能把计划保存或格式合法当成科学计算已完成。
